Render bold text and bullet lists in chat answers (v1.0.1)

The smoke test showed raw Markdown symbols in answers (for example
**April 5-7, 2027** and "* ITC C304 ..."). The chat page now renders
**bold** and "*"/"-" bullet lines with DOM nodes only (no innerHTML),
so answer text cannot inject HTML. Retrieval, prompts, models and
answers are unchanged.
